# Imagen del Código QR de Cobro (Yape)

Esta carpeta contiene únicamente el archivo de imagen correspondiente al código QR estático propio de la cuenta de cobro Yape para pruebas de pago digital sin comisión en el minimarket.

> **Nota para desarrolladores y Agentes de IA:**  
> Esta carpeta **no** contiene código fuente ni lógica de escaneo.
